# PPT 去 AI 味

用于中文 PPT 起草与修改的 Skill，帮助减少空泛文案、重复句式和机械套版，保留事实、引用与已有设计。

## 适用场景

- 课程作业、工作汇报和已有 PPT 润色。
- 修改空话、重复总结与过度整齐的表达。
- 调整文字密度、基本版式和阅读顺序。

## 使用方法

### 直接复制给 AI

打开 [SKILL.md](SKILL.md)，复制全文给你使用的 AI，再提供原稿、截图或大纲和修改要求。只发送技能名称不会自动加载内容。

示例：

> 请按这份 skill 修改我的 PPT，减少空话和重复表达，保留数据、引用与现有配色。按原页码给出可替换的标题和正文；如果能编辑文件，请直接输出修改后的文件。

### 在支持 Skills 的工具中使用

下载仓库，将包含 `SKILL.md` 的文件夹命名为 `ppt-humanize`，放入工具指定的技能目录。按工具说明调用；支持名称调用的环境可使用 `$ppt-humanize`。

是否能读取、编辑和导出 PPT 取决于所用工具。仅支持文字的 AI 可提供逐页改稿。风格修改不等于来源鉴定，不保证任何检测器结果。
